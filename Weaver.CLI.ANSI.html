    Use format/1 like IO.ANSI.format/2. Calls IO.ANSI so all escapes supported there can be used here.

    [:display_erase_all, {:cursor_position, {10, 10}}, :red, "Hello world!"]
|> Weaver.CLI.ANSI.format()
|> IO.puts()
