    Modules

    Weaver
    Weaver.Api

    Weaver.Api is a behaviour that describes an api Weaver.LLM can use

    Weaver.Api.Anthropic

    Client for anthropic messages api. Built on https://anthropix.hexdocs.pm/Anthropix.html

    Weaver.Api.Bedrock

    Client for AWS Bedrock api. Built on https://ex-aws-bedrock.hexdocs.pm/ExAws.Bedrock.html

    Weaver.Api.Bedrock.Request

    Weaver.Api.Bedrock.Request handles converting sso credentials to something for ExAws and wraps ExAws.Bedrock.request to inject those creds when calling Bedrock.

    Weaver.Api.BedrockMock

    Mock AWS Bedrock api

    Weaver.Api.Ollama

    Ollama api client

    Weaver.Api.OllamaMock

    Mock Ollama api client

    Weaver.Api.OpenAI

    Client for OpenAI apis

    Weaver.Application

    The entrypoint for the application

    Weaver.CLI

    Weaver.CLI handles displaying messages to the user in the terminal.

    Weaver.CLI.ANSI

    ANSI control sequences not provided by IO.ANSI

    Weaver.CLI.ANSI.Macros

    Helpers to reduce boilerplate for handling ANSI control sequences

    Weaver.CLI.IO

    Allows the user prompt to be handled async. Relies on Weaver.CLI.Term for configuring the terminal.

    Weaver.CLI.SlashCommands

    Helpers for Weaver.CLI slash commands like /exit, /clear, etc.

    Weaver.History

    Persists conversation messages to JSONL files.

    Weaver.LLM

    Maintains conversation context and manages LLM interactions.

    Weaver.Personas

    Weaver.Personas handles loading persona details from persona.json and PERSONA.md files.

    Weaver.Tools

    Manages tool execution and responses.

    Weaver.Tools.Tool

    A behaviour for implementing tools as elixir modules
